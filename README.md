# Movie Streaming Search

This folder is ready to publish with GitHub Pages.

## Publish it

1. Create a new GitHub repository, or open the repository you want to use.
2. Upload `index.html` and the entire `images` folder to the repository root.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then click **Save**.

GitHub will display the public web address after the site finishes publishing.

## Customize it

Open `index.html` in a text editor. The visual styling is in the `<style>` section, the page content is in the `<body>`, and the sample movie data is near the top of the `<script>` section.

This is a static demonstration site. The IMDb buttons link to IMDb search results; streaming availability and sample titles are illustrative.
